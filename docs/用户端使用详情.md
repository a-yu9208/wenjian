# 博客文件管理系统 — 用户端使用详情

## 一、系统概述

本系统是一个基于 Web 的多媒体文件管理平台，用户可通过浏览器注册登录，上传和管理视频、文件等多媒体内容，接收系统通知。系统采用响应式设计，支持桌面端和移动端访问。

---

## 二、用户注册与登录

### 2.1 注册流程

注册页面路径：`/register/`

| 字段 | 是否必填 | 说明 |
|------|----------|------|
| 用户名 | 是 | 唯一，不可重复 |
| 密码 | 是 | — |
| 邮箱 | 是 | 唯一，不可重复 |
| 电话 | 否 | 选填 |

注册成功后默认角色为「普通用户」，自动跳转至登录页。

```
┌──────────┐     ┌──────────┐     ┌──────────┐     ┌──────────┐
│ 填写表单  │────▶│ 后端校验  │────▶│ 创建账号  │────▶│ 跳转登录 │
│          │     │ 用户名唯一│     │ role=user│     │          │
│          │     │ 邮箱唯一  │     │          │     │          │
└──────────┘     └──────────┘     └──────────┘     └──────────┘
                       │
                       │ 校验失败
                       ▼
                 ┌──────────┐
                 │ 显示错误  │
                 │ 返回表单  │
                 └──────────┘
```

### 2.2 登录流程

登录页面路径：`/login/`

- 输入用户名和密码
- Django authenticate 验证
- 基于 Session 的认证机制，会话有效期 24 小时
- 每次请求自动刷新会话时间

```
┌──────────┐     ┌──────────┐     ┌──────────┐
│ 输入账密  │────▶│ 身份验证  │────▶│ 跳转首页  │
└──────────┘     └─────┬────┘     └──────────┘
                       │
                       │ 验证失败
                       ▼
                 ┌──────────┐
                 │ 提示错误  │
                 │ 返回登录  │
                 └──────────┘
```

### 2.3 退出登录

点击导航栏用户菜单中的「退出登录」，清除 Session 后跳转至登录页。

## 四、视频模块

### 4.1 视频列表页（首页）

路径：`/`

- 展示所有已审核通过（approved）且公开（public）的视频
- 按观看次数降序、上传时间降序排列
- 每个视频卡片显示：封面缩略图、标题、观看次数、上传时间

### 4.2 视频详情页

路径：`/videos/<id>/`

- 视频播放器（支持 Range 请求的流式播放）
- 显示标题、简介、上传者信息、观看次数、点赞数
- 支持大文件视频流式传输

### 4.3 视频上传

路径：`/videos/upload/`（需登录）

| 字段 | 是否必填 | 说明 |
|------|----------|------|
| 标题 | 是 | 视频标题 |
| 简介 | 否 | 视频描述 |
| 视频文件 | 是 | 最大 1GB |
| 封面图片 | 否 | 可选上传 |

上传后状态为「待审核」（pending），需管理员审核通过后才会在首页公开展示。

## 五、文件模块

### 5.1 文件列表页

路径：`/files/`

- 展示所有已审核通过且公开的文件
- 显示文件类型图标、标题、大小、下载次数、上传时间

### 5.2 文件详情页

路径：`/files/<id>/`

- 文件基本信息展示
- 下载按钮
- 查看次数统计

### 5.3 文件上传

路径：`/files/upload/`（需登录）

| 字段 | 是否必填 | 说明 |
|------|----------|------|
| 标题 | 是 | 文件标题 |
| 描述 | 否 | 文件描述 |
| 文件 | 是 | 最大 1GB |
| 文件类型 | 是 | 图片/文档/压缩包/音乐/其他 |

上传后同样进入待审核状态。

## 六、个人中心

路径：`/profile/`（需登录）

### 6.1 个人信息管理

- 查看和编辑：邮箱、电话
- 上传/更换头像

### 6.2 我的视频

展示当前用户上传的所有视频，每个视频卡片包含：

- 封面缩略图
- 标题
- 状态标签：待审核（黄色）/ 已通过（绿色）/ 已驳回（红色）
- 可见性标签：公开（绿色）/ 私密（灰色）
- 观看次数
- 操作按钮：「设为私密」或「转为公开」

### 6.3 我的文件

与视频类似，展示用户上传的所有文件及其状态，支持切换可见性。

### 6.4 可见性切换流程

```
用户点击切换按钮
       │
       ├── 公开 → 私密
       │   └──▶ 直接生效，状态不变
       │        按钮更新为「转为公开」
       │        Toast 提示「已设为私密」
       │
       └── 私密 → 公开
           └──▶ 弹出确认框
                「转为公开后需要管理员审核」
                     │
                     ├── 取消 ──▶ 无操作
                     │
                     └── 确定 ──▶ visibility=public
                                  status=pending（重新审核）
                                  按钮更新为「设为私密」
                                  状态标签更新为「待审核」
                                  Toast 提示
```

特点：操作后页面不刷新，按钮和标签原地更新，不影响当前浏览位置。

## 七、通知系统

### 7.1 通知铃铛

- 位于导航栏右侧，显示未读通知数量角标
- 每 30 秒自动刷新未读数
- 点击跳转至通知列表页

### 7.2 通知列表页

路径：`/notifications/`（需登录）

- 按时间倒序展示所有通知
- 未读通知：蓝色左边框 + 红色圆点标记
- 已读通知：半透明样式
- 操作：
  - 单条标记已读
  - 全部标记已读（页面顶部按钮）

### 7.3 自动通知触发场景

| 场景 | 通知内容示例 |
|------|-------------|
| 视频审核通过 | 您上传的视频「xxx」已通过审核 |
| 视频审核驳回 | 您上传的视频「xxx」未通过审核 |
| 文件审核通过 | 您上传的文件「xxx」已通过审核 |
| 文件审核驳回 | 您上传的文件「xxx」未通过审核 |
| 视频转为公开 | 您的视频「xxx」已转为公开状态 |
| 文件转为公开 | 您的文件「xxx」已转为公开状态 |

#### 通知流转图

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│ 管理员执行    │────▶│ 系统根据模板  │────▶│ 通知写入数据库│
│ 审核/发通知   │     │ 生成通知内容  │     │ is_read=False│
└──────────────┘     └──────────────┘     └──────┬───────┘

                                          ┌──────────────┐
                                          │ 用户导航栏    │

                                                  │
                                                  ▼
                                          ┌──────────────┐
                                          │ 用户点击查看  │

```

## 八、弹窗公告

当管理员发布了活跃公告时，用户访问任意页面会看到弹窗通知。

### 弹窗样式

- 居中显示，半透明遮罩背景
- 显示公告标题和内容
- 底部：「一周内不再弹出」复选框 + 「我知道了」按钮

### 弹窗行为

| 用户操作 | 效果 |
|----------|------|
| 点击「我知道了」（不勾选） | 本次浏览器会话内不再弹出，关闭浏览器后重新弹出 |
| 勾选「一周内不再弹出」后点击 | 7 天内不再弹出（Cookie 记录） |
| 管理员发布新公告 | 无论之前选择如何，新公告都会重新弹出 |

## 十、页面路由表

| 路径 | 页面 | 需要登录 |
|------|------|----------|
| `/` | 视频列表（首页） | 否 |
| `/videos/<id>/` | 视频详情 | 否 |
| `/videos/upload/` | 上传视频 | 是 |
| `/files/` | 文件列表 | 否 |
| `/files/<id>/` | 文件详情 | 否 |
| `/files/upload/` | 上传文件 | 是 |
| `/register/` | 注册 | 否 |

| `/notifications/count/` | 未读通知数（API） | 是 |
| `/notifications/read/` | 标记已读（API） | 是 |

| `/api/file/<id>/change-visibility/` | 切换文件可见性（API） | 是 |
