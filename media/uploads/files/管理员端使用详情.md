# 博客文件管理系统 — 管理员端使用详情

## 一、系统概述

本系统是基于 Django 框架开发的多媒体文件管理平台，支持视频和文件的上传、审核、管理与分发。采用 B/S 架构，前端使用 Bootstrap 5 + jQuery，后端使用 Django 5.0 + MySQL，通过 Gunicorn + Nginx 部署，支持 HTTPS 安全访问。

### 1.1 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | HTML5、CSS3、Bootstrap 5、jQuery 3.7、Bootstrap Icons |
| 后端 | Python 3.11、Django 5.0、Django REST Framework |
| 数据库 | MySQL 8.0（utf8mb4 字符集） |
| Web 服务器 | Nginx（反向代理 + 静态文件 + SSL） |
| 应用服务器 | Gunicorn（多 Worker 进程模型） |
| 操作系统 | OpenCloudOS（Linux） |

### 2.2 核心数据表说明

| 表名 | 说明 | 关键字段 |
|------|------|----------|
| User | 用户表，继承 AbstractUser | role（角色）、avatar（头像）、phone（电话） |
| Video | 视频表 | status（审核状态）、visibility（可见性）、view_count |
| FileItem | 文件表 | file_type（文件类型）、status、download_count |
| VideoComment | 视频评论/审核意见 | video（关联视频）、reviewer（审核人） |
| FileComment | 文件评论/审核意见 | file_item（关联文件）、reviewer（审核人） |
| Notification | 用户通知 | user（接收者）、is_read（已读状态） |
| NotificationTemplate | 自动通知模板 | key（模板标识）、支持变量替换 |
| Announcement | 弹窗公告 | is_active（是否启用） |
| SiteSettings | 网站全局设置 | 单例模式，仅一条记录 |
| FileCategory | 文件分类 | name（分类名）、icon（图标） |

管理面板访问地址：`/admin/`，仅管理员（is_staff / is_superuser / role='admin'）可访问。

### 3.2 概览页

展示系统核心数据统计卡片：

| 指标 | 说明 |
|------|------|
| 待审核 | 当前待审核的视频 + 文件总数 |
| 已通过 | 审核通过的视频 + 文件总数 |
| 总内容 | 系统中所有视频 + 文件总数 |

同时展示最新待审核内容列表，支持快捷审核操作（通过/驳回）。

### 3.3 审核管理

分为「待审核视频」和「待审核文件」两个区域，展示标题、上传者、可见性、大小、上传时间，每条记录提供「✓ 通过」和「✗ 驳回」按钮，操作通过 AJAX 异步执行。

### 3.4 通知系统

#### 3.4.1 发送通知

管理员可选择接收人（单个用户或全部用户），填写标题和内容，点击发送即时送达。

#### 3.4.2 通知模板

系统预置 6 个自动通知模板，审核操作时自动触发：

| 模板标识 | 触发场景 | 默认标题 |
|----------|----------|----------|
| video_approved | 视频审核通过 | 您的视频已通过审核 |
| video_rejected | 视频审核驳回 | 您的视频未通过审核 |
| file_approved | 文件审核通过 | 您的文件已通过审核 |
| file_rejected | 文件审核驳回 | 您的文件未通过审核 |
| video_public | 视频转为公开 | 您的视频已转为公开 |
| file_public | 文件转为公开 | 您的文件已转为公开 |

模板支持变量替换：`{title}` 替换为内容标题，`{username}` 替换为用户名。管理员可随时编辑模板内容。

#### 3.4.3 通知记录

展示最近 20 条通知发送记录，包含接收人、标题、已读/未读状态、发送时间。

### 3.5 弹窗公告

管理员可创建、编辑、启用/停用、删除弹窗公告。已有公告以条状列表展示，点击展开编辑。

#### 弹窗展示逻辑流程图

```

       ▼

       │
       ▼

       │

       │
       └── 勾选「一周内不再弹出」
```

### 3.6 内容管理

管理所有视频和文件：

| 功能 | 说明 |
|------|------|
| 搜索 | 按标题、上传者实时过滤 |
| 筛选 | 按可见性（公开/私密）下拉筛选 |
| 排序 | 标题、上传者、时间列点击表头升序/降序切换 |
| 更改状态 | 下拉选择待审核/通过/驳回，立即生效 |
| 删除 | 永久删除内容及关联文件，需二次确认 |

### 3.7 用户管理

| 功能 | 说明 |
|------|------|
| 搜索 | 按用户名、邮箱实时过滤 |
| 排序 | 用户名、注册时间列可排序 |
| 更改角色 | 下拉切换普通用户/管理员，同步更新 is_staff |
| 重置密码 | 弹窗输入新密码（最少 6 位），PBKDF2 哈希存储 |
| 启用/禁用 | 切换用户 is_active 状态，禁用后无法登录 |
| 超管保护 | 以上操作均不可对超级管理员执行 |

## 四、API 接口列表

### 4.1 管理端接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/admin/` | 管理面板页面 |
| POST | `/admin/action/` | 管理操作统一入口（JSON Body） |

`/admin/action/` 通过请求体中的 `type` 字段区分操作：

| type 值 | 说明 | 参数 |
|---------|------|------|
| review | 审核操作 | model, action(approve/reject/make_public), id |
| send_notification | 发送通知 | user_id, title, content |
| save_template | 保存通知模板 | id, title, content |
| save_announcement | 创建/编辑公告 | id(可选), title, content |
| delete_announcement | 删除公告 | id |
| toggle_announcement | 启用/停用公告 | id |
| change_status | 更改内容状态 | model, id, status |
| delete_content | 删除内容 | model, id |
| change_user_role | 更改用户角色 | id, role |
| reset_user_password | 重置用户密码 | id, password |
| toggle_user_active | 启用/禁用用户 | id |

### 4.2 公共接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/announcement/` | 获取当前活跃公告 |
| GET | `/notifications/count/` | 获取当前用户未读通知数 |
| GET | `/notifications/` | 通知列表页面 |
| POST | `/notifications/read/` | 标记通知已读 |

## 六、安全设计

| 安全措施 | 实现方式 |
|----------|----------|
| HTTPS 加密传输 | Nginx SSL 证书 + HTTP 自动跳转 HTTPS |
| CSRF 防护 | Django CSRF 中间件 + Token 验证 |
| 权限控制 | @login_required + @user_passes_test 装饰器 |
| 密码安全 | Django PBKDF2 哈希存储，不可逆 |
| 超管保护 | 后端拒绝对超级管理员的角色/密码/状态修改 |
| 文件上传限制 | 最大 1GB，文件类型白名单校验 |
| HSTS | Nginx 配置 Strict-Transport-Security 头 |
| CORS 控制 | django-cors-headers 中间件 |
| 会话安全 | Session 有效期 24 小时，每次请求刷新 |
